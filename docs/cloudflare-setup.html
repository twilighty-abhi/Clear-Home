Cloudflare setup for our flat app

We run a small web app for our flat (notes, chores, shopping list) on a Raspberry Pi at home. We'd like to reach it from outside at flat.example.com, behind a Cloudflare sign-in so only the flatmates get in. The Pi side is already done; this page covers the Cloudflare side.

Public addressflat.example.com
Points tohttp://localhost:8642
Runs onRaspberry Pi 3 · arm64
Who gets inFlatmates' emails, one-time code

1Add the domain (skip if it's already in the account)

  1. In the Cloudflare dashboard, choose Add a domain, enter example.com, and pick the Free plan.
  2. Cloudflare shows two nameservers. Send them to whoever manages the domain, to set at the registrar.
  3. Wait until Cloudflare shows the domain as Active. There are no other records on this domain that need copying.

2Create the tunnel

  1. Go to Zero Trust → Networks → Tunnels → Create a tunnel, type Cloudflared, name it clear-home.
  2. On the install screen, choose Debian and arm64-bit. Copy only the long token (the text after --token). The program is already installed on the Pi, so no command needs running.
  3. Send the token to whoever runs the Pi, privately (not in a group chat). It works like a password for the tunnel. They save it on the Pi (in ~/clearhome/tunnel-token), and the tunnel shows Healthy within about a minute.
  4. Add a Public Hostname with these settings:
FieldValue
Subdomainflat
Domainexample.com
Pathleave empty
Service typeHTTP
URLlocalhost:8642

Cloudflare then creates this DNS record by itself. Nothing to add by hand:

TypeNameTargetProxy
CNAMEflat<tunnel-id>.cfargotunnel.comProxied

3Add the sign-in (Cloudflare Access)

Please do this before sharing the link. The app trusts Cloudflare's sign-in to say who someone is; without it, people arriving through the tunnel only get a limited guest page, but the sign-in should be in place.

Go to Zero Trust → Access → Applications → Add an application → Self-hosted:

SettingValue
Application nameFlat app
Application domainflat.example.com (no path)
Session duration1 month, so phones stay signed in
Login methodOne-time PIN (emailed code)
Policy nameFlatmates
ActionAllow
IncludeEmails: the flatmates' email addresses

Leave everything else at its default. The app reads the signed-in email from the Cf-Access-Authenticated-User-Email header that Access adds, so nothing else needs configuring.

4Check it works

  • The tunnel clear-home shows Healthy.
  • Opening https://flat.example.com in a private window shows the Cloudflare sign-in, not the app.
  • Signing in with one of the allowed emails opens the flat app.
  • Any other email is refused.

5Good to know

  • No ports are opened on the home router. The Pi connects out to Cloudflare.
  • Everything on the Pi runs under a normal user account. Pi-hole on the same Pi isn't touched.
  • To switch it off, delete the public hostname or the tunnel. The app keeps working at home.
  • Adding a flatmate later: add their email to the Flatmates policy.
Questions about the Pi or the app: ask whoever runs the Pi. Thanks for setting this up!
